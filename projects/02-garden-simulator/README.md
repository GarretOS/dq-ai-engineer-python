# 🌱 Garden Simulator

Garden Simulator is a text-based Python game where you forage for seeds, plant crops, tend them through unique growth stages, and harvest the results. It demonstrates object-oriented programming with a base `Plant` class and specialized plant subclasses.

## Try it interactively

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/GarretOS/dq-ai-engineer-python/blob/main/projects/02-garden-simulator/garden_simulator.ipynb)

Run the notebook in Google Colab and enter actions such as `forage`, `plant`, `tend`, `harvest`, `inventory`, `help`, or `quit`.

## Files

- `garden_simulator.py` — standalone command-line game and source code.
- `garden_simulator.ipynb` — interactive Google Colab demonstration.
- `requirements.txt` — dependency manifest; this project uses only the Python standard library.

## Run locally

```bash
python garden_simulator.py
```
