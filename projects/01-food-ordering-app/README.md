# 🍔 Jet Delivers Food Ordering App

Jet Delivers is a menu-driven Python food ordering application. It demonstrates dictionaries, functions, loops, conditionals, user input, cart management, sales tax, and checkout logic.

## Try it interactively

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/GarretOS/dq-ai-engineer-python/blob/main/projects/01-food-ordering-app/food_ordering_app.ipynb)

Run the notebook in Google Colab and use the interactive `input()` prompts to add items, modify the cart, and check out.

## Files

- `food_ordering_app.py` — standalone command-line application and source code.
- `food_ordering_app.ipynb` — interactive Google Colab demonstration.
- `requirements.txt` — dependency manifest; this project uses only the Python standard library.

## Run locally

```bash
python food_ordering_app.py
```
